# Brand profiles

Each brand, person or organization gets its own folder here: `brands/<slug>/`. The core reads brand settings only from these folders; adding a brand never means editing core code.

The profile schema (`brand.yaml`, `sources.yaml`, `tokens.json`, `motion-system.md`, `assets/`) arrives in roadmap phase 4.1, and the setup wizard (`stagorix brand new`) in 4.2.
